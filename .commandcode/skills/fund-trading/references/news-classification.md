# 雷点 / 热点判定说明

## 数据从哪来

1. **联网搜索**（Agent 内置 `web_search`）——新闻、公告、研报标题与摘要。
2. **东财基金档案页**（脚本抓取）——基金经理、任职起始、成立日、规模、申购/赎回状态、单日申购上限。
3. **东财重仓股页**（脚本抓取）——最新报告期前十大重仓股及占净值比例。

脚本自己**不发起新闻搜索**（中文财经页面反爬严重、结果不稳定），只负责：

- 生成建议搜索词（`news.mjs profile/queries`）
- 对搜索结果的标题 + 摘要做确定性关键词打分（`news.mjs scan`）
- 保存结论并判断新鲜度（`news.mjs verdict`）

## 输入格式

`scan` / `report --input` 接受：

```json
[
  { "title": "标题", "url": "https://...", "snippet": "摘要", "date": "2026-10-29" }
]
```

也接受 `{ "results": [ ... ] }`。`date` 可省略，脚本会从标题/摘要/URL 里猜
`YYYY-MM-DD` 或 `YYYY年M月D日`。

## 关键词与权重

| 类别 | 关键词 | 权重 |
| --- | --- | --- |
| 高危雷点 | 清盘、终止、暂停申购、暂停赎回、暂停大额申购、巨额赎回、立案、处罚、违规、造假、违约、爆雷、踩雷、退市、离任、诉讼、冻结 | 标题命中 4.5 / 正文 3 |
| 一般雷点 | 调查、变更、警示、风险提示、下跌、大跌、暴跌、亏损、回撤、减持、下调、业绩不佳、跑输、规模缩水、迷你基金、清盘风险 | 标题 3 / 正文 2 |
| 强热点 | 创新高、大涨、涨停、净流入、获批、超预期、政策支持、利好 | 标题 4.5 / 正文 3 |
| 一般热点 | 上涨、反弹、回暖、走强、增长、突破、龙头、景气、热门、增持、分红、修复、加仓、重仓、风口 | 标题 2.5 / 正文 1.5 |

同一关键词在一条结果里只计一次。

## 时间衰减

| 距今天数 | 系数 |
| --- | --- |
| ≤ 7 天 | 1.5 |
| ≤ 30 天 | 1.2 |
| ≤ 90 天 | 1.0 |
| ≤ 365 天 | 0.7 |
| > 365 天 | 0.5 |
| 未知 | 0.9 |

单条得分 = 关键词权重和 × 系数；总分 = 所有结果得分之和。

## 立场判定

- `risk`：雷点总分 ≥ 5 且 ≥ 热点总分 × 1.5
- `hot`：热点总分 ≥ 5 且 ≥ 雷点总分 × 1.5
- `mixed`：两边都有分但不满足上述比例
- `neutral`：其余

结构化硬伤（规模 < 5 亿、暂停申购/赎回、成立 < 1 年、经理任职 < 180 天）会强制把
`hot` 降为 `mixed`，`neutral` 升为 `risk`。

## 置信度

- `high`：证据 ≥ 5 条且单边得分 ≥ 12
- `medium`：证据 ≥ 3 条且单边得分 ≥ 6
- `low`：其余

## 与下单的关系

`order.mjs new --side buy`：

| 资讯状态 | 行为 |
| --- | --- |
| 无结论 / 超过 `news.maxAgeHours`（默认 24h） | 拒绝生成，退出码 3；加 `--skip-news` 可跳过 |
| `stance=risk` | 拒绝生成，退出码 2 |
| `stance=hot` | 生成，提示"注意追高风险" |
| `stance=mixed` | 生成，提示"控制仓位" |
| `stance=neutral` | 生成，提示"不建议仅凭资讯操作" |

卖出不受资讯拦截，但会把资讯结论写进指令单并给出提示。

## 局限（必须向用户说明）

1. **关键词启发式**：会误判（例如"实施分红后净值下跌"同时命中两边）。
2. **不验证真伪**：只对搜索结果做分类，不核实新闻事实。
3. **搜索质量决定结论**：结果太少或太旧时置信度为 `low`，不应据此重仓。
4. **摘要级**：只看标题和摘要，不读公告全文；重大事项仍需打开原文。
5. **没有行情预测能力**：资讯结论只回答"近期公开信息偏正面还是负面"。

## 红线

- 不得编造搜索结果、链接或日期。
- 搜索失败或结果为空时，如实说明，不能伪造结论。
- 向用户展示结论时必须附上证据标题与链接，并标注置信度。
